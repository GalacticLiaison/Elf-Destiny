# Rites of the Aeluran Weavers faith. The High Matriarch (d_high_matriarch) is Head of Faith for all of them.
# The mainline rite MUST be scripted and named in the faith type (main_rite): a faith that has scripted rites but no
# declared main rite does not get an automatic one, the engine promotes the first scripted rite instead.
# Doctrines are left out on purpose: a rite inherits whatever it does not define from the faith and religion.
# In history, a character or province follows one of these with "rite = <key>" instead of "religion = aeluran_weavers".

# The mainline rite that the Elves of the Feyswood and the great houses follow. Shares the name and loc of the faith.
# "religion = aeluran_weavers" in history resolves to this rite.
aeluran_mainline_rite = {
	name = aeluran_weavers
	desc = aeluran_weavers_desc
	faith = aeluran_weavers

	color = { 0.53 0.03 0.03 }
	icon = spark_faith

	tenets = {
		tenet_aeluran_sisters
		tenet_divine_marriage
		tenet_sanctity_of_nature
		tenet_communal_identity
		# tenet_esotericism
	}
}
