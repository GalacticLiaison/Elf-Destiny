# DORMANT (PM decision 2026-10-04): this situation is defined but never started. The hooks that started it are commented
# out in common/on_action/aeluran_matronate_map_on_actions.txt, and the Order button opens the vanilla clerical-regions
# map instead (gui/aeluran_order_button.gui). Why it exists: CK3 lets a mod add map modes only from the engine's fixed
# colourings, and the situation colouring is the one that paints only a chosen set of counties. This situation painted
# each Matronate in its own colour (sub-region slots synced from the clerical regions, see
# common/scripted_effects/aeluran_matronate_map_effects.txt) and its own window (gui/window_aeluran_matronates.gui, a
# fork of window_situation.gui) switched the map to it. Shelved because the vanilla clerical-regions map already colours
# the Matronates and the Red Sister temple markers live on the political map. Kept for a fuller Aeluran Order situation
# later. Full account: modkit reports/proposals/2026-10-02-matronate-map-mode.md.
#
