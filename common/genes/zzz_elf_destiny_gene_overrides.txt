# Elf Destiny -- deliberate overrides of individual vanilla genes.
#
# Each gene below REPLACES the vanilla gene of the same name (the gene database is keyed by gene
# name, and this file sorts after vanilla's 01_/10_ files). Everything not listed here is left to
# vanilla, so a game patch that adds templates (eye_fold_shape_02_neg, complexion_smooth_1, the
# lower_stubble body hair, eye_lower_lid_def_02, ...) is picked up automatically instead of being
# shadowed by a stale full-file copy. After a patch, re-diff only these three genes against vanilla.
#
#   gene_age                 vanilla + filled-in `no_aging` (infant proportions for characters whose
#                            age is frozen; "no more adult babies").
#   gene_bs_body_shape       vanilla minus `visible = no` (body shape selectable in the ruler designer).
#   gene_balding_hair_effect vanilla indices, baldness templates neutralised (no baldness in game).
