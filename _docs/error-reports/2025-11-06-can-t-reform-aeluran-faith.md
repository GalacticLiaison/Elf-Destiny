Prior to 1.18 (and the miniupdates) I used to be able to reform the Aeluran religion and the game rules changing number of religious sites required to reform always worked when I set the number to 0. But with the new update there's some conflict with the coronation event and I get a popup telling me I can't reform the faith because I'm not "anointed" -- which I believe only happens if you are an emperor and do the coronation event. Also, ED now ignores game rules lowering number of holy site requirements to reform -- I get one holy site automatically wherever I put the portal, but I still have to do expeditions (twice) to two more sites in order to qualify.
