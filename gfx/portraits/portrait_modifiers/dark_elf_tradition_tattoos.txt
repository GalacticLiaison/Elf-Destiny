# Dark Elf Beta - tradition-driven tattoos.
# Adults whose culture has the dark_elf_tattooing_common parameter (from
# tradition_the_old_ways_dark) roll each tattoo slot at ~25%. Across the six
# slots below that gives ~82% of such characters at least one tattoo
# (0.75^6 ~= 0.18 with none), per PM's ~80% target. Rolls are deterministic
# per character (portrait seed), so a character's ink never changes.
# Everyone else always resolves to no_tattoo (the gene default).
# Right arm / hand genes only define no_tattoo, so they have no groups here;
# the remaining chest genes are left to ruler-designer customization only.

# Eye group runs at 4x weight scale (base 400, options 11 each) so the nine
# patterns can share the same ~25% total slot chance: 99/399 ~= 24.8%.
